# Grill UI

Скилл для Codex и Claude Code: согласовать решения перед реализацией в терминальном интерфейсе. Агент собирает вопросы и варианты, а вы можете обсудить каждый вопрос в отдельном чате. Основной агент получает только подтверждённые ответы, без переписки этих чатов.

Полезен, когда нужно разобрать требования, выбрать подход или уточнить границы задачи до написания кода. В Herdr открывается отдельная вкладка; вне Herdr интерфейс запускается в вашем терминале.

## Установка

Нужны Linux или macOS, Python 3.11+, Node.js с `npx` и установленный Codex CLI или Claude Code с выполненным входом. Для отдельной вкладки нужен Herdr 0.9+. Windows без Linux-окружения не поддерживается.

Установите через [Vercel Skills](https://skills.sh/docs), выбрав Codex или Claude Code:

```sh
npx skills@latest add yakovlevs01/grill-ui --skill grill-ui -g
```

Откройте новую сессию агента после установки. Зависимости интерфейса ставятся в отдельное Python-окружение `~/.local/share/grill-ui/venv` при первом открытии раунда. Для этого нужны uv или python3 с модулями venv и pip, а также доступ к сети. Поставить их заранее можно командой:

```sh
python3 "$HOME/.agents/skills/grill-ui/scripts/grill_herdr.py" install
```

Если установщик Skills показал другой каталог скилла, подставьте его путь.

## Использование

Попросите агента:

> Используй grill-ui, чтобы согласовать первую версию моего приложения. Хочу сохранять статьи и возвращаться к ним позже. До согласования код не пиши.

Агент подготовит раунд вопросов. Выберите варианты или напишите свой ответ. Если нужно разобраться, откройте чат вопроса. Enter подтверждает ответ и переводит к следующему вопросу; после всех ответов нажмите "Отправить все ответы".

Следующие раунды появятся в той же вкладке. Прошлые вопросы остаются в списке: ответы на них только для чтения, но чаты можно продолжать, а кнопкой "Пересмотреть" попросить агента вернуться к решению. Вкладка закроется, когда вы подтвердите агенту итоговую картину.

В Herdr агент продолжит автоматически. Вне Herdr он даст команду запуска интерфейса; после отправки ответов вернитесь к агенту и напишите "Готово". Обсуждения используют ваш агентский CLI и расходуют его лимиты.

## Обновление

На каждом ПК:

```sh
npx skills@latest update
```

Skills получает изменения из GitHub. Если изменились зависимости интерфейса, следующее открытие раунда обновит окружение само. Синхронизация между ПК не автоматическая. Версии отмечаются git-тегами.
